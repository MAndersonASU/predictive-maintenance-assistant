# Intelligent Predictive Maintenance and Technical Knowledge Assistant

A portfolio AI engineering project that combines:

- Real MetroPT-3 industrial sensor data
- Predictive-maintenance machine learning
- Technical-document retrieval and RAG
- AI agents and tool routing
- Evaluation, monitoring, APIs, and deployment

## Project Goal

Build a production-oriented system that can analyze compressor sensor data, estimate equipment failure risk, retrieve relevant maintenance information, and provide evidence-based technical assistance.
