# Intelligent Predictive Maintenance and Technical Knowledge Assistant 

## Project Goal

Build a production-oriented AI system that:
1. analyzes MetroPT-3 compressor sensor data;
2. predicts equipment faults or abnormal operating conditions;
3. retrieves relevant technical documentation;
4. explains predictions using a RAG-based assistant;
5. supports future deployment, monitoring, and evaluation.
